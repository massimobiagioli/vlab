# ADR-0010: Absolute path overrides and fail-closed private directories

- Status: Accepted
- Date: 2026-11-12
- Supersedes: —
- Superseded by: —

## Context

ADR-0002 places settings and data in per-user directories, allows the
`VLAB_CONFIG_DIR`, `VLAB_DATA_DIR`, and `VLAB_DB_PATH` overrides, requires
mode `0700` for directories and `0600` for files on Unix, and requires failing
closed when private storage cannot be established. It does not say how
overrides are validated, or what happens when a directory already exists with
looser permissions.

## Decision

1. Each override must be an absolute path. A relative or empty override is a
   configuration error (exit 2). Nothing is ever resolved against the current
   working directory.
2. Without overrides, paths are `<config dir>/vlab/settings.yaml` and
   `<data dir>/vlab/vlab.db`, using the `directories` base directories. If no
   home directory can be determined and no override is set, resolution fails
   with an actionable error.
3. `ensure_private_dir` creates missing directories, including missing
   parents, with mode `0700`. An existing directory is accepted only if it is
   a real directory (not a symlink or file) and grants no group or other
   permissions. VLab never changes the permissions of an existing directory;
   it refuses one that is unsafe, with a `chmod 700` hint (exit 4).
4. `create_private_file` creates files with mode `0600` and `create_new`, so
   an existing file or link at the path is never reused.
5. Path resolution and creation run only when a command needs storage. Help,
   version, and argument errors never touch the filesystem.

## Consequences

- A misconfigured override fails visibly instead of writing somewhere
  unexpected.
- Pointing an override at a shared directory such as `/tmp` fails; users
  must choose a private directory.
- On non-Unix platforms only the file-type checks apply (A-19).

## Alternatives considered

- **Tighten existing permissions automatically**: rejected; it could change a
  directory the user shares on purpose, or fail on one they do not own.
- **Accept relative overrides**: rejected; the result would depend on the
  working directory, which ADR-0002 and `STACK.md` forbid as a default.
