# ADR-0012: GitHub Actions CI and supply-chain policy

- Status: Superseded
- Date: 2026-11-12
- Supersedes: —
- Superseded by: ADR-0013

## Context

`STACK.md` requires rustfmt, Clippy, tests, `cargo audit`, and `cargo deny`
on every change; CI on every supported platform; daily security scans; one
dependency-update tool (Dependabot or Renovate); and checks that reject
unmaintained and vulnerable dependencies. Assumption A-19 targets macOS and
Linux on GitHub Actions. `.docs/SECURITY.md` requires least-privilege CI.

## Decision

1. Use GitHub Actions. `ci.yml` runs on every push and pull request. Its
   Linux and macOS matrix runs fmt, clippy with `-D warnings`, and tests, all
   `--locked`. A Linux job runs `cargo audit` and `cargo deny check`.
2. `security.yml` runs `cargo audit` and `cargo deny check advisories` daily
   and on demand. A failed advisory fetch fails the run.
3. Workflow permissions are `contents: read`. Actions are pinned to full
   commit SHAs. Only `actions/checkout` (without persisted credentials) and
   `actions/cache` are used. Tools are installed with `cargo install --locked`
   at pinned versions.
4. Use Dependabot, weekly, for Cargo and GitHub Actions. Do not add Renovate.
5. `deny.toml` denies yanked, unmaintained, and unsound crates, wildcard
   versions, unknown registries, and git sources. It allows the licenses
   `Apache-2.0`, `MIT`, and `Unicode-3.0`. The only exception is MPL-2.0 for
   `option-ext`, an unmodified transitive dependency of `directories`. No
   advisory is ignored.
6. Branch protection and other repository settings are documented as manual
   steps in `.docs/CI.md`.

## Consequences

- Every change is checked on both target platforms with the same gates as a
  local run.
- New licenses or advisories fail CI until someone makes an explicit decision.
- Building tools from source makes cold CI runs slower; caches reduce that.

## Alternatives considered

- **Renovate**: rejected; `STACK.md` asks for one tool, and Dependabot needs
  no extra service.
- **Third-party installer or toolchain actions**: rejected; each one adds a
  supply-chain dependency with write-capable code in CI.
- **Allowing MPL-2.0 globally**: rejected in favor of a crate-scoped
  exception.
- **Tag-pinned actions**: rejected; tags can be moved.
