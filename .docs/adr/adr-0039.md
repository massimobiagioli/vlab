# ADR-0039: Dashboard-only entry point

- Status: Accepted
- Date: 2026-11-13
- Supersedes: —
- Superseded by: —
- Amends: ADR-0038 (command surface only), ADR-0009 (entry point)

## Context

ADR-0038 introduced `vlab labs`, `vlab projects`, `vlab agents`, and
`vlab settings` as direct group entry points. The product owner now wants a
single `vlab` entry point that opens a home dashboard, with group navigation
inside the interface. The public help surface should expose only `-h`/`-v`
(and their long forms); the group subcommands and the clap `help` subcommand
are no longer menu items.

## Decision

1. A bare `vlab` in a terminal opens the home dashboard. In a non-TTY stream it
   prints help instead of blocking.
2. The home dashboard lists Laboratories, Projects, Agents, and Settings.
   `Enter` opens the selected group, `1`–`4` jump directly, `Esc` returns from a
   group to home, and `q` quits.
3. Remove the public `labs`, `projects`, `agents`, `settings`, and `help`
   subcommands. Keep `-h`/`--help` and `-V`/`--version`.
4. Legacy action flags remain hidden compatibility aliases during the
   deprecation window. They are not part of the documented surface and are not
   shown in help.
5. The dashboards, actions, safety rules, color policy, and terminal lifecycle
   from ADR-0038 remain unchanged.

## Consequences

- There is one discoverable entry point and one navigation model.
- Scripts cannot use group subcommands; they must use the hidden legacy flags
  until a future explicit non-interactive action surface is specified.
- `vlab labs` and `vlab help` are usage errors.
- The feature checklist remains implemented; only the entry-point contract
  changes.

## Alternatives considered

- **Keep direct group subcommands**: rejected by the product owner; the home
  dashboard is the single entry point.
- **Keep the clap `help` subcommand**: rejected; it is redundant with `-h`.
- **Remove hidden legacy flags immediately**: deferred; it would break the
  existing non-interactive validation surface in the same change.
